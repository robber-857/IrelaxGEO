# Irelax AU 网站整改需求文档

版本：1.0　日期：2026-10-19　范围：irelax.com.au

## 1 项目目标

在保留现有 WordPress 电商平台和购物流程的基础上，使产品、品牌、门店和政策信息真实一致，关键内容能从 HTML 中读取，结构化数据能正确解析并对应页面实际内容。交付以明确的页面和字段验收为准，搜索和 AI 引用表现作为后续观察指标，不承诺排名、引用率或销售增幅。

第一批先处理 FAQ 数据、产品品牌与标识字段、规格与保修冲突、错误面包屑；不需要为此重建网站。

## 5 重要实施修正

1. **保修期限不能照抄报告。** 本次首页显示五年，报告与示例使用三年。先确定生效日期、SKU、部件与人工范围及排除条件，再改文案。30 天退款也应链接完整条件，不能扩大为无条件承诺。
2. **SKU、MPN、GTIN 分工不同。** 保留库存系统 SKU；型号可在有证据时映射 MPN。没有真实 GTIN 不填，不把型号随意写入已有 SKU。ProductGroup 用于真实变体集合，不强制所有商品采用同一类型。参见 [Google 产品变体文档](https://developers.google.com/search/docs/appearance/structured-data/product-variants)。
3. **后台路径是待验证入口。** 报告所称 Rank Math 一次设置影响全部商品，需要核实当前版本、许可、实际品牌 taxonomy 和 Schema 输出源。不得把全局设置成功等同于全部产品验收通过。
4. **FAQ 的目标是内容和标记正确。** Google 官方更新记录说明 FAQ 富结果已停止展示，不以出现 FAQ 富结果作为验收条件。JSON 换行可以正确转义，不要求为单行而牺牲内容；使用 JSON 编码器生成。参见 [Google 官方更新记录](https://developers.google.com/search/updates)。
5. **AU/NZ 的公司关系需要负责人再次确认。** 报告称同一法律主体，但当前未收到对应证明和 NZ 管理范围。共用 Organization ID 是待评估建模方案，不保证权重或 AI 引用优势转移。先核实法律名称、地区运营关系和原有节点引用，再决定共用 ID 或关联组织模型。
6. **hreflang 取决于页面等价性。** 两端 200 不是充分条件；需判断内容、语言与地区适用性，并双向维护。参见 [Google 多语言页面文档](https://developers.google.com/search/docs/specialty/international/localized-versions)。
7. **非按摩椅商品不能自动下架或 noindex。** 应依据真实业务、搜索表现和页面质量决定，不因报告认为主题不集中而处理在售商品。移出 sitemap 也不等于禁止索引。
8. **llms.txt 为可选项。** 500 的根因值得检查，但不属于 Google 必需的优化文件。sitemap 索引时间与子条目最大时间不同，也需结合生成机制判断，不能仅凭时间差断定缓存失效。
9. **评论不可根据相似文字直接删除。** 先区分重复导入、同一评论重复渲染与真实独立评论；更正需要保留审计记录。
10. **待更新不等于已知漏洞。** 截图中的更新和主题许可提示进入运行维护分支，另行评估兼容性；不把大量升级和内容优化绑成同一次发布。

## 6 范围与非功能要求

首轮范围：AU 站首页、FAQ、Biovis、Healer X、按摩椅分类及相关全局 Schema；扩展范围为 About、Showrooms、城市页、两篇代表文章和中文页。实际 URL 和页面 ID 在后台盘点时确认。

本阶段交付需求、步骤和验收文档。实际线上修改、NZ 同步修改、批量升级、商品下架、评论删除、URL 迁移及真实付款不包含在本次已完成工作中。每批实施需有具体变更范围和证据。

- 保持商品选择、加入购物车、购物车金额、结账入口、搜索、移动导航和试用预约流程可用。
- 标准字段优先使用现有数据源，避免 Rank Math、主题、WPCode 和自定义插件重复输出相同实体。
- 新正文应服务用户阅读，不添加隐藏关键词或只供爬虫看的事实描述。
- 不把客户、订单、凭据和私密后台内容写入公开证据或版本库。
- 每批保存改动前后页面和配置，具有可执行的回滚方法。
- 首轮技术验收：目标页面 JSON-LD 解析成功率 100%；已确认的关键事实冲突清零；样板产品标识和品牌正确；关键购物与预约流程无新增阻断。
- 后续观察：以基线比较自然曝光、点击、目标页面引用和转化路径；无论技术验收结果如何，均不提前宣称业务效果已实现。
